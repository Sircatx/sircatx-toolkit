# Sircatx 工具箱

一款原生中文、可持续扩展的 Obsidian 工具箱。

## 功能

- 分别设置桌面端和移动端的锁定行为。
- 按文件夹、标签或属性值建立视图锁定规则。
- 使用笔记属性为单篇笔记启用阅读模式锁定。
- 输入规则时自动提示现有文件夹、标签、属性及属性值。
- 在阅读视图或实时预览的行内代码后显示 📋，点击即可复制；代码块不受影响。
- 支持桌面端和移动端。

## 使用方法

安装并启用插件后，打开 **设置 → Sircatx 工具箱**。

设备行为优先级最高，每种设备可以选择：

- **遵循现有规则**：依次应用单篇笔记覆盖和匹配规则。
- **始终使用阅读视图**：在当前设备上强制所有笔记使用阅读视图。
- **禁用锁定**：在当前设备上允许自由切换视图。

### 单篇笔记覆盖

在笔记属性中添加 `阅读模式锁定`：

```yaml
阅读模式锁定: reading
```

支持的值：

- `是`：阅读模式
- `reading`：阅读视图

属性名称可在插件设置中修改。

### 规则优先级

1. 设备行为
2. 单篇笔记覆盖
3. 文件夹、标签或属性规则

## 手动安装

将以下文件复制到 `.obsidian/plugins/sircatx-toolkit/`：

- `main.js`
- `manifest.json`
- `styles.css`

重新加载 Obsidian 后，在第三方插件列表中启用“Sircatx 工具箱”。请勿同时启用功能重复的独立插件。
